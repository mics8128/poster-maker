# Information Architecture: Poster Maker 拼版功能

## 主要使用者與任務

主要使用者是需要把圖片輸出成可列印 PDF 的一般使用者。核心流程只有一頁：載入圖片、選擇輸出模式、調整必要尺寸、確認預覽、產生 PDF。

## 單頁結構

1. **來源圖片**：選擇或拖曳圖片。兩種模式共用。
2. **輸出模式**：
   - 海報分割：一張圖片放大並切成多頁 A4。
   - 一張多份：同一張圖片在單張紙上自動拼版。
3. **模式設定**：只顯示目前模式需要的欄位。
   - 海報分割：A4 張數、指定成品尺寸。
   - 一張多份：成品尺寸、外部紙張尺寸、四側安全邊界。
4. **主要操作**：產生對應 PDF。
5. **結果與錯誤**：在操作旁立即顯示。
6. **預覽**：右側持續顯示紙張、圖片、裁切線和安全邊界。

## 內容優先順序

- 立即顯示：來源、模式、主要尺寸、最佳排列結果、產生按鈕。
- 條件顯示：自訂欄列、自訂成品尺寸、拼版安全邊界。
- 摘要顯示：份數、欄列、是否旋轉、紙張與成品尺寸。
- 不新增頁面或深層導航。

## 關鍵流程

### 海報分割

載入圖片 → 選海報分割 → 選張數或成品尺寸 → 查看多頁預覽 → 產生多頁 A4 PDF。

### 一張多份

載入圖片 → 選一張多份 → 選 A5/A6/A7 或自訂成品尺寸 → 設定外部紙張 → 設定四側安全邊界 → 自動計算最多份數 → 查看單頁預覽 → 產生單頁 PDF。

## 尺寸語意

- **成品尺寸**：每份的外框與裁切線尺寸，也是最佳排列的占用尺寸。
- **安全邊界**：從成品尺寸向內扣除。圖片完整置入剩餘區域，不裁切、不變形；比例不同處留白。
- **外部紙張尺寸**：輸出 PDF 的單頁尺寸。
- 拼版可旋轉整份成品，以取得更多份數；圖片與安全邊界隨成品一起旋轉。

## 拖曳行為

整個視窗接受單一圖片檔。拖入合法格式後，行為與「選擇圖片」相同；不合法或多檔時顯示錯誤，並保留原本圖片。
